# Diabetes Prediction using Machine Learning

My first Machine Learning project.

## Project Goal
Build a Machine Learning classification model to predict whether a patient is likely to have diabetes based on medical data.

## Tools & Technologies
- Python
- Pandas
- Scikit-learn
- Logistic Regression
- Jupyter Notebook / Google Colab

## 📊 Dataset
The dataset contains patient health information such as:
- Pregnancies
- Glucose
- Blood Pressure
- Skin Thickness
- Insulin
- BMI
- Age

## 🤖 Model
I used Logistic Regression as the classification algorithm.

## 🔄 Project Workflow
1. Load the dataset
2. Explore and clean the data
3. Prepare features and target
4. Split the data into training and testing sets
5. Train the Logistic Regression model
6. Make predictions
7. Evaluate the model

## Purpose
This project is mainly a learning project to understand the basic Machine Learning workflow and build my first classification model.
